# COVID-19 Data Exploration and Visualization Project
## Project Description
This project provides a comprehensive analysis and visualization of the global impact of the COVID-19 pandemic using SQL, Excel, and Tableau. The objective is to explore how COVID-19 affected different countries and continents in terms of case counts, death rates, and vaccination progress, and to draw meaningful insights from the data.
## Dataset Used
- <a href="https://github.com/ManasaraniB/Covid19-Project/blob/main/CovidDeaths1.xlsx"> CovidDeaths </a>
It Contains daily reports of COVID-19 deaths, total cases, population data, and other demographic metrics by country.

CovidVaccinations1.xlsx: Includes vaccination-related data like new vaccinations per day, aggregated per country.
