# COVID-19 Data Exploration and Visualization Project
## Project Description
This project provides a comprehensive analysis and visualization of the global impact of the COVID-19 pandemic using SQL, Excel, and Tableau. The objective is to explore how COVID-19 affected different countries and continents in terms of case counts, death rates, and vaccination progress, and to draw meaningful insights from the data.
## Dataset Used
- <a href="https://github.com/ManasaraniB/Covid19-Project/blob/main/CovidDeaths1.xlsx"> CovidDeaths </a>
It Contains daily reports of COVID-19 deaths, total cases, population data, and other demographic metrics by country.

- <a href="https://github.com/ManasaraniB/Covid19-Project/blob/main/CovidVaccinations1.xlsx"> CovidVaccinations </a>
It Includes vaccination-related data like new vaccinations per day, aggregated per country.
# Key Goals
-Analyze the global spread and impact of COVID-19 using real-world data.

-Calculate key metrics such as death rates, infection rates, and vaccination coverage.

-Compare countries and continents to identify trends and outliers.

-Create interactive visualizations in Tableau for clear communication of insights.
## Dashboard
The project culminated in an interactive Tableau dashboard that visually presents these insights. Visualizations likely include global summary metrics, heatmaps of deaths by continent, bar charts of top affected countries, time-series graphs of cases and vaccinations, and maps to show regional disparities.

## Conclusion
This project provided a data-driven perspective on the global COVID-19 pandemic by analyzing cases, deaths, and vaccination trends across regions. Using SQL for in-depth analysis and Tableau for visualization, uncovered key insights into the severity, spread, and response efforts of various countries. The project demonstrates the power of data analytics in understanding public health crises and supports informed decision-making through clear, visual storytelling.
